## 1. Executive summary

Vision Touch Ltd, a Greater London construction and property-improvement company, engaged
Auztec Innovations to design and build a premium, conversion-focused marketing website from
the ground up, with the commercial goal of turning visitors into qualified enquiries.

Auztec delivered a **22-page, fully bespoke website** — no templates — with an original brand
system, a real project gallery, an intelligent lead-capturing chatbot assistant, a complete
technical SEO foundation, and a zero-server, globally-distributed hosting and CI/CD pipeline.
The site launched on the client's own domain with automated deployment, so every future update
goes live within minutes of a single approval.

**Headline outcomes**
- A high-end brand presence built to compete with established London construction firms.
- Four always-on enquiry channels (quote form, WhatsApp, click-to-call, AI chatbot) feeding a
  single inbox.
- 24/7 automated lead qualification via a custom conversational assistant.
- A launch-ready technical SEO footprint (structured data, sitemap, canonical architecture)
  targeting local Greater London search.
- Fast, resilient, near-zero running cost hosting on Cloudflare's global edge.

## 2. The client & the brief

Vision Touch Ltd offers loft conversions, extensions, renovations, carpentry & joinery, kitchen
and bathroom installation, structural work, roofing, flooring, garage conversions and general
building services across Greater London, serving homeowners, property investors, developers and
contractors.

They arrived with a logo and brand colours but **no existing website**. The brief:

- A premium, trustworthy presence that stands up against strong UK competitors — *not* a
  template look.
- Built for **lead generation**: quote requests, calls, WhatsApp and email enquiries.
- Fast, mobile-first, and cheap to host and maintain.
- Individual, SEO-optimised pages for every service.
- Deployable to affordable hosting without a fragile always-on backend.

## 5. Approach & process

A structured, phase-gated delivery:

1. **Discovery & strategy** — brand audit, competitor review (UK construction/renovation), goal
   definition (lead generation), sitemap and content model.
2. **Design system** — colour, type, components and motion language derived from the client's
   own brand, validated against premium-competitor benchmarks.
3. **Build** — component-driven, template-generated pages for consistency and easy future edits;
   real client photography and video integrated and optimised.
4. **Conversational AI** — researched common homeowner questions; built a knowledge base from
   the site content; engineered a typo-tolerant intent engine with safe, on-brand answers and a
   pre-filling lead-capture flow; added an optional LLM upgrade path.
5. **SEO & performance hardening** — structured data, metadata, media optimisation, Lighthouse-
   friendly loading.
6. **QA** — responsive testing (desktop/tablet/mobile), automated chatbot intent test suite,
   accessibility passes, cross-browser checks.
7. **Launch & DevOps** — Git + Cloudflare Pages CI/CD, domain and SSL, canonical redirects,
   edge caching.
8. **Handover** — full documentation, an editable content model, and a defined upgrade roadmap.

- **Enterprise-grade delivery on a small-business budget** — global CDN, automatic HTTPS,
  serverless functions, and push-to-deploy CI/CD at near-zero running cost.

## 7. Technical architecture

- **Front end:** Semantic HTML5, modern CSS (custom-property design tokens, responsive, reduced-
  motion aware), vanilla JavaScript. No heavyweight framework — deliberately lean for speed and
  longevity.
- **Build system:** A small Node generator produces all 22 static pages from shared templates +
  structured content/config, keeping header, footer, SEO and components consistent site-wide.
- **Serverless backend:** Cloudflare Pages Functions (`/api/chat`, `/api/chat/lead`) for the
  optional AI layer and lead routing — no always-on server, no database dependency.
- **Conversational AI:** In-house intent engine (fuzzy matching, stemming, context memory,
  knowledge retrieval) with an optional, environment-gated LLM layer (Cloudflare Workers AI or
  any OpenAI-compatible provider) and grounded, guard-railed prompting.
- **Forms & data:** Web3Forms-based enquiry pipeline (no backend mail server), with client-side
  fallback so no lead is ever lost.
- **Hosting & CI/CD:** Cloudflare Pages, deploying automatically from the `main` branch of a
  Git repository. Custom domain, free SSL, apex→www redirect, edge caching, security headers.
- **Testing:** Automated intent-matching test suite; documented QA process.
